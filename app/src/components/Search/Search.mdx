# Search

Search fields let users query and filter content with an optional clear control.

## When to use

- Filtering lists, tables, or directories
- Global or scoped search in a toolbar

## When not to use

- Choosing from a fixed enum — use **Dropdown**
- Multi-field advanced search — build a dedicated form

## Accessibility

- Use `type="search"` or `role="searchbox"` with a visible label
- Clear button needs an accessible name
