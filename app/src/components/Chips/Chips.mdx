# Chips

Chips represent compact labels, filters, or selections.

## When to use

- Filter tags and removable selections
- Compact status or category labels

## When not to use

- Primary actions — use **Button**
- Long sentences — use body text

## Types

Primary, positive, negative, and warning color roles are available.

## Accessibility

- Removable chips need an accessible remove action
- Disabled chips should not receive focus
