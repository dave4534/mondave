# IconButton

Icon buttons are square, icon-only controls for compact actions.

## When to use

- Toolbar actions (close, edit, more)
- Repeated actions where space is limited

## When not to use

- Actions that need a text label for clarity — use **Button**
- Navigation to another page — use **Link**

## Accessibility

- **Required:** `aria-label` describing the action
- Visible `:focus-visible` ring on keyboard focus
