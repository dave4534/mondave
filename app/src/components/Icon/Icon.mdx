## Overview

Icon component unifies Lucide icons, direct Lucide usage, and custom SVG icons in Mondave.

<Canvas of={IconStories.Overview} />

### Import

```tsx
import { Icon } from '@mondave/core';
```

## Usage

- Always wrap icons with `Icon` when you need Mondave semantic colors.
- Try to always use icons alongside text or provide a tooltip / `label` to accommodate the icon.
- Import icons by name from `lucide-react` so unused icons are tree-shaken.
