# Divider

Dividers separate content into distinct sections.

## When to use

- Visual separation between list groups or form sections
- Toolbar or menu item grouping

## When not to use

- Spacing alone — use layout tokens
- Decorative lines without semantic separation

## Orientation

Horizontal and vertical dividers are supported.

## Accessibility

- Use `role="separator"` when the divider conveys structure
- Prefer spacing when separation is purely visual
