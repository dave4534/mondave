# Slider

Sliders let users pick a value or range along a track.

## When to use

- Numeric settings where approximate values are fine (volume, opacity)
- Range filters with visual feedback

## When not to use

- Exact numeric entry — pair with **TextField** or use stepper
- Binary choices — use **Toggle**

## Accessibility

- Thumbs must be keyboard operable
- Expose `aria-valuemin`, `aria-valuemax`, and `aria-valuenow`
