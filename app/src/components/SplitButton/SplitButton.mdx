# SplitButton

Split buttons combine a primary action with a menu of secondary alternatives.

## When to use

- Save with “Save as…” alternatives
- Primary action plus related variants

## When not to use

- Unrelated actions in one control — use separate buttons
- Single action — use **Button**

## Accessibility

- Both segments need discernible names
- Menu trigger must declare expanded state
