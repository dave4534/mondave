# Tabs

Tabs organize related content into switchable panels within the same view.

## When to use

- 2–6 peer sections at the same level
- Settings categories or record detail views

## When not to use

- Sequential wizard steps — use **MultiStepIndicator**
- Deep hierarchy — use navigation

## Variants

Normal, counter, and stretched layouts.

## Accessibility

- Tab list uses `role="tablist"`; panels use `role="tabpanel"`
- Active tab should be focusable and announced
