# DatePicker

Date pickers let users choose dates or ranges from a calendar surfaced via a text field.

## When to use

- Scheduling, deadlines, or reporting date ranges
- When exact calendar dates matter

## When not to use

- Relative times (“in 2 hours”) — use plain text or presets
- Simple year-only input — use **Dropdown**

## Accessibility

- Calendar grid needs labeled days and keyboard navigation
- Pair with a visible label on the trigger field
