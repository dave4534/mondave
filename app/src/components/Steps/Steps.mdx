# Steps

Steps navigate sequential content with previous/next controls and optional gallery dots.

## When to use

- Carousels, guided tours, or paginated subflows
- Step-by-step media or instructions

## When not to use

- Hierarchy location — use **Breadcrumbs**
- Form wizards with labeled steps — use **MultiStepIndicator**

## Accessibility

- Announce current step index
- Previous/next buttons need clear labels
