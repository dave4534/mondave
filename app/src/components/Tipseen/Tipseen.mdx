# Tipseen

Tipseen provides guided onboarding callouts with optional media and actions.

## When to use

- First-run product tours
- Feature discovery anchored to UI elements

## When not to use

- Critical errors — use **Modal** or **AlertBanner**
- Persistent help — use documentation links

## Accessibility

- Allow users to dismiss and return later
- Trap focus only when the tip blocks required action
