# Spacing

Spacing tokens come from the Figma **Spacing** collection and apply under `[data-theme="mode-1"]`. Storybook’s **Spacing** toolbar sets that mode on `body` (default: Mode 1).

## Scale

| Token | Value | Typical use |
|-------|-------|-------------|
| `--space-2` | 2px | Hairline offsets |
| `--space-4` | 4px | Tight gaps, small radius |
| `--space-8` | 8px | Icon gaps, compact padding |
| `--space-12` | 12px | Chip padding, small stacks |
| `--space-16` | 16px | Default component gaps |
| `--space-20` | 20px | Mid-size stacks |
| `--space-24` | 24px | Section / modal padding |
| `--space-32` | 32px | Large section spacing |
| `--space-40` | 40px | Extra-large stacks |
| `--space-48` | 48px | Page-level margins |
| `--space-64` | 64px | Hero / sparse layouts |
| `--space-80` | 80px | Marketing-scale gaps |

## Visual ramp

<div style={{ display: 'flex', flexDirection: 'column', gap: 'var(--space-12)', margin: 'var(--space-24) 0' }}>
  {[4, 8, 12, 16, 24, 32, 48].map((n) => (
    <div key={n} style={{ display: 'flex', alignItems: 'center', gap: 'var(--space-16)' }}>
      <code className="type-text3-normal" style={{ width: 96 }}>--space-{n}</code>
      <div style={{ height: 12, width: `var(--space-${n})`, background: 'var(--primary-color)', borderRadius: 2 }} />
    </div>
  ))}
</div>

## When to use

- **Padding inside components** — match Figma (`--space-8` to `--space-16` is common)
- **Gaps between siblings** — flex/grid `gap`
- **Border radius** — many controls use `--space-4`

## Troubleshooting

If corners look sharp and padding collapses:

1. Storybook **Spacing** toolbar is **Mode 1**
2. `body` has `data-theme="mode-1"` (set by the preview shell)
