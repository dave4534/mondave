# Color

Semantic color tokens map Figma roles to CSS variables (`tokens.css`). Switch the Storybook **Color** toolbar (Light / Dark / Black) to preview each mode — Light is `:root`, Dark uses `.dark`, Black uses `[data-theme="black"]`.

## Semantic roles

| Role | Variable | Usage |
|------|----------|-------|
| Primary | `--primary-color` | Primary actions, key emphasis |
| Brand | `--brand-color` | Brand-specific accents |
| Primary text | `--primary-text-color` | Body and headings |
| Secondary text | `--secondary-text-color` | Supporting text, labels |
| UI background | `--ui-background-color` | Page and canvas surfaces |
| UI border | `--ui-border-color` | Dividers, input borders |
| Positive | `--positive-color` | Success states |
| Negative | `--negative-color` | Errors, destructive actions |
| Warning | `--warning-color` | Caution states |
| Disabled background | `--disabled-background-color` | Disabled controls |
| Link | `--link-color` | Text links |

## Content palette

Figma also exports content colors (berry, grass-green, royal, etc.) as `--content-color-*` for tags, status chips, and illustrations.

## Guidelines

- Prefer semantic tokens (`--primary-color`) in components over raw content palette values unless the design specifies a content color.
- Check Light, Dark, and Black with the toolbar before shipping.
- Pair link color with Text2 / Text1 **link** type styles when underlining.
